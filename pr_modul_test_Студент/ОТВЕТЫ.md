## Задание 8 — Вывод

### 1. С какими трудностями столкнулись?

- Нужно было запускать команды из папки с файлами
- При ошибке в функции pytest показывает, какой именно тест упал
- Для `average_grade` использовался `pytest.approx()` для сравнения дробных чисел

### 2. Почему модульное тестирование важно?

Модульные тесты позволяют быстро проверить, что каждая функция работает правильно после изменений. Если что-то сломалось — тест сразу покажет ошибку. Это экономит время и снижает количество багов в программе.
