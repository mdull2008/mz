## 2. Описание реализованных модулей и функций

### `converter.py` — модуль конвертации

**Длина (основное задание):**

| Функция | Описание |
|---------|----------|
| `meters_to_kilometers(meters)` | Метры → километры (÷ 1000) |
| `kilometers_to_meters(kilometers)` | Километры → метры (× 1000) |
| `meters_to_centimeters(meters)` | Метры → сантиметры (× 100) |
| `centimeters_to_meters(centimeters)` | Сантиметры → метры (÷ 100) |
| `meters_to_millimeters(meters)` | Метры → миллиметры (× 1000) |
| `millimeters_to_meters(millimeters)` | Миллиметры → метры (÷ 1000) |

**Вес (дополнительное задание):**

| Функция | Описание |
|---------|----------|
| `kilograms_to_grams(kilograms)` | Килограммы → граммы (× 1000) |
| `grams_to_kilograms(grams)` | Граммы → килограммы (÷ 1000) |

**Время (дополнительное задание):**

| Функция | Описание |
|---------|----------|
| `hours_to_minutes(hours)` | Часы → минуты (× 60) |
| `minutes_to_hours(minutes)` | Минуты → часы (÷ 60) |
| `minutes_to_seconds(minutes)` | Минуты → секунды (× 60) |
| `seconds_to_minutes(seconds)` | Секунды → минуты (÷ 60) |
| `hours_to_seconds(hours)` | Часы → секунды (× 3600) |
| `seconds_to_hours(seconds)` | Секунды → часы (÷ 3600) |

Все функции проверяют входные данные: при отрицательном значении выбрасывается `ValueError`.

### `main.py` — консольное приложение

| Функция | Описание |
|---------|----------|
| `print_menu()` | Вывод меню с выбором операции |
| `parse_number(value)` | Преобразование строки в число с обработкой ошибок |
| `run()` | Главный цикл: выбор операции → ввод → результат |

### `tests/test_converter.py` — модуль тестирования

Содержит 33 автоматических теста на базе PyTest.

## 5. Выводы

### Какие навыки были получены в ходе работы

- Создание структурированного Python-проекта с пакетами и модулями
- Написание функций с типизацией (`float` → `float`) и валидацией входных данных
- Разработка консольного приложения с интерактивным меню
- Написание автоматических тестов с фреймворком **PyTest**
- Тестирование граничных случаев (ноль, отрицательные значения)
- Тестирование исключений с помощью `pytest.raises`
- Использование параметризованных тестов (`@pytest.mark.parametrize`)
- Обработка ошибок пользовательского ввода (строки вместо чисел)

### Какие возникли сложности и как они были решены

1. **Импорт модулей при запуске тестов.** PyTest не находил пакет `unit_converter`. Решение: запускать тесты из корня проекта командой `python3 -m pytest unit_converter/tests/ -v`.

2. **Проверка исключений.** Нужно было убедиться, что при отрицательных значениях выбрасывается именно `ValueError`. Решение: использован конструкция `with pytest.raises(ValueError)`.

3. **Обработка ввода с запятой.** Пользователь может ввести `2,5` вместо `2.5`. Решение: в `parse_number` добавлена замена запятой на точку перед `float()`.
