# ProjectBAnk — WinForms

Простое банковское приложение на **Windows Forms** (.NET 8).

## Запуск (Windows)

```bash
cd ProjectBAnk
dotnet run
```

Или откройте `ProjectBAnk.sln` в Visual Studio и нажмите F5.

## Что делает программа

1. Вводите имя и начальный баланс → нажимаете «Создать счёт»
2. Вводите сумму → «Положить» или «Снять»
3. **Нейросеть ML.NET** проверяет операцию на мошенничество
4. Если операция подозрительная — появится предупреждение с % риска
5. Внизу видна история операций
6. Кнопка **«Предложения»** — загрузка JSON с сайта и анализ нейросетью

## Анализ предложений с сайта (JSON + нейросеть)

1. Нажмите **«Предложения»** на главном окне
2. **«Загрузить JSON»** — подключение к `https://dummyjson.com/products`
3. **«Анализ ML.NET»** — нейросеть определяет выгодные предложения

Файлы:
- `Services/OfferApiClient.cs` — получение JSON с сайта
- `Services/OfferAnalyzer.cs` — нейросеть для разбора предложений
- `OffersForm.cs` — окно с таблицей и результатами

## Структура проекта

```
ProjectBAnk/
├── Program.cs              — точка входа, запуск окна
├── MainForm.cs             — логика (кнопки, проверки)
├── OffersForm.cs           — окно анализа предложений
├── Models/
│   ├── BankAccount.cs      — бизнес-логика счёта
│   ├── Offer.cs            — модель предложения из JSON
│   └── TransactionInput.cs — данные для нейросети
└── Services/
    ├── FraudDetector.cs    — нейросеть (мошенничество)
    ├── OfferApiClient.cs   — HTTP + JSON с сайта
    └── OfferAnalyzer.cs    — нейросеть (предложения)
```

## Нейросеть — проверка мошенничества

Используется **ML.NET** (библиотека Microsoft для машинного обучения в C#).

Модель смотрит на:
- сумму операции
- время (ночь = подозрительно)
- сколько операций за последний час
- снятие или пополнение
- долю суммы от баланса

При первом запуске модель **обучается автоматически** и сохраняется в `fraud-model.zip`.

## WinForms и WPF — очень просто

### Что это вообще?

Это способы сделать **оконную программу** для Windows (кнопки, поля ввода, меню).

```
Твой код (C#)  →  WinForms/WPF  →  Windows рисует окно на экране
```

### WinForms — как конструктор LEGO

- Окно = **Form** (форма)
- Кнопка = **Button**, поле = **TextBox**, надпись = **Label**
- Ты **перетаскиваешь** элементы в Visual Studio (дизайнер)
- Нажал кнопку → срабатывает метод `btn_Click` — ты пишешь, что делать

**Плюсы:** очень просто, быстро начать.  
**Минусы:** сложнее делать красивый современный интерфейс.

### WPF — как HTML + стили

- Окно тоже есть, но интерфейс описывается в **XAML** (похоже на разметку)
- Можно менять внешний вид через **стили** и **шаблоны**
- Есть **привязка данных** (Data Binding): изменилось число в коде → на экране обновилось само

**Плюсы:** красивый UI, гибкая вёрстка.  
**Минусы:** сложнее для новичка.

### Сравнение в одной таблице

| | WinForms | WPF |
|---|----------|-----|
| Как рисуем UI | Код + дизайнер | XAML + код |
| Сложность | Низкая | Средняя |
| Красота UI | Обычная | Высокая |
| Только Windows | Да (WPF) / почти (WinForms) | Да |

### Как работает наше приложение (WinForms)

```
Program.Main()
    └── Application.Run(new MainForm())   ← открывает окно

Пользователь нажал «Положить»
    └── btnDeposit_Click()
            └── _account.Deposit(сумма)   ← меняем баланс в коде
            └── lblBalance.Text = ...     ← обновляем надпись на экране
```

**Главная идея:** интерфейс (кнопки) отделён от логики (`BankAccount`). Форма только показывает данные и вызывает методы модели.
