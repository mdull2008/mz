# ФанТвит

Прототип фанфикшен-платформы с социальной лентой: каталог историй,
профили авторов и читателей, блог-посты в стиле Twitter и форма публикации
нового фанфика.

## Возможности MVP

- Главная страница с позиционированием сервиса и статистикой сообщества.
- Каталог фанфиков с фандомами, рейтингами, статусами, тегами и метриками.
- Лента коротких постов авторов и читателей с ответами, репостами и лайками.
- Профили авторов с подписчиками, количеством работ и описанием.
- Форма редактора для создания карточки фанфика и анонса в блог.
- Адаптивная верстка для десктопа, планшетов и телефонов.

## Запуск

```bash
npm install
npm run dev
```

## Сборка
