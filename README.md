# FicPulse

**FicPulse** — социальная платформа для фанфиков: Фикбук + Twitter в одном месте.

## Возможности

- **Фанфики** — главы, фандомы, рейтинги, теги, **обложки**
- **Лента** — посты, лайки, подписки
- **Уведомления** — лайки, комментарии, подписки, новые главы
- **Личные сообщения** — переписка между пользователями
- **Профили** — блог, работы, био

## Быстрый старт

```bash
npm install
npx prisma migrate dev
npm run db:seed
npm run dev
```

Откройте http://localhost:3000

Подробная инструкция для Visual Studio и хостинга: **[DEPLOY.md](./DEPLOY.md)**
