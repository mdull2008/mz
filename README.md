# 📖 FicSpace — Фанфик-платформа с социальной сетью

**FicSpace** — это полноценная платформа, объединяющая возможности **FicBook** (написание и чтение фанфиков) и **Twitter** (блог, посты, подписки, лента). Авторы и читатели могут вести аккаунт, публиковать посты и фанфики в одном месте.

---

## ✨ Возможности

### 📖 FicBook-часть
- Написание многоглавных фанфиков с удобным редактором
- Метаданные: фэндом, рейтинг (G / PG / PG-13 / R / NC-17), жанры, предупреждения, пейринг, теги
- Статус произведения (продолжается / завершено / заморожено)
- Встроенный читалка с переключением глав
- Комментарии к произведениям
- Лайки и закладки
- Фильтрация и поиск по фэндому, рейтингу, жанру, статусу, словам

### 🐦 Twitter-часть
- Посты до 500 символов с индикатором длины
- Персональная лента (посты людей, на которых подписан)
- Лайки, репосты, ответы на посты
- Система подписок (follow/unfollow)

### 👤 Профиль
- Отдельные страницы авторов и читателей
- Список постов и произведений на профиле
- Счётчики подписчиков/подписок
- Редактирование профиля (имя, биография, аватар, локация, сайт)

### 🔍 Поиск и Библиотека
- Глобальный поиск историй по тексту, тегам, фэндому
- Фильтры и сортировка (по дате, просмотрам, лайкам)
- Библиотека с закладками

## 🛠 Технологии

| Слой | Технология |
|------|-----------|
| Frontend | React 18 + TypeScript + Vite |
| Стили | Tailwind CSS (тёмная тема) |
| State | Zustand |
| Backend | Node.js + Express |
| База данных | SQLite (better-sqlite3) |
| Аутентификация | JWT |
| Контейнеризация | Docker + Docker Compose |

## 🚀 Запуск

### Локально (разработка)

```bash
# Бэкенд
cd backend
npm install
node src/index.js
# Запустится на http://localhost:3001

# Фронтенд (в новом терминале)
cd frontend
npm install
npm run dev
# Запустится на http://localhost:5173
```

### Docker

```bash
docker-compose up --build
# Откройте http://localhost
```
