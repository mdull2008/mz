# FicWave

FicWave — статический MVP сайта для фанфиков с социальной лентой в стиле Twitter.

## Что есть в прототипе

- каталог фанфиков с поиском, фильтрами по фандому и рейтингу;
- профили авторов и читателей с переключением текущего аккаунта;
- публикация новой работы с первой главой;
- блог-посты до 280 символов, лайки и репосты;
- чтение глав в модальном окне;
- отзывы, избранное и счетчики прочтений;
- демо-данные и сохранение состояния в `localStorage`.

## Запуск

Откройте `index.html` в браузере или запустите простой локальный сервер:

```bash
python3 -m http.server 8000
```

После этого сайт будет доступен по адресу `http://localhost:8000`.
